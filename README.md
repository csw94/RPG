# Chronicles of Pixel

Pygame CE로 만든 한글 2D 탑뷰 RPG입니다. 마을과 필드를 탐험하고, 대장간에서 장비를
마련한 뒤 별도의 던전에 도전하세요.

게임 기획서: [별빛 결계의 수호자 게임 기획서 (PDF)](docs/별빛%20결계의%20수호자%20게임%20기획서.pdf)

## Windows에서 다운로드 및 실행

1. [최신 릴리즈 페이지](https://github.com/csw94/RPG/releases/latest)를 엽니다.
2. 릴리즈의 Assets에서 **ChroniclesOfPixel.exe**를 다운로드합니다.
3. 다운로드한 EXE 파일을 더블 클릭해 실행합니다. Python 설치는 필요하지 않습니다.

세이브 데이터는 Windows 사용자 앱 데이터 폴더에 저장됩니다. EXE에 한글 폰트가
포함되어 있어 별도의 에셋 폴더 없이 실행할 수 있습니다.

## 조작 방법

- 이동: 방향키 또는 WASD
- 상호작용·상자 열기·문/계단 이용: 스페이스바
- 저장: F5 또는 필드 화면의 저장 버튼
- 타이틀로 돌아가기: ESC (현재 진행 상황을 저장합니다)
- 전투: 방향키 또는 WASD로 선택한 뒤 Enter/스페이스바, 또는 마우스로 행동 선택
- 상점: 방향키로 물품 선택 후 Enter, ESC로 마을에 돌아가기

## 세이브 슬롯

타이틀 화면에서 **모험 이어하기**를 선택하면 3개의 슬롯 중 저장 기록을 고를 수
있습니다. 새 모험은 **새 모험 시작**을 선택한 뒤 슬롯을 지정하세요. 이미 기록이
있는 슬롯은 덮어쓰기 전에 확인을 받습니다. 기존 저장 기록은 1번 슬롯에 보존됩니다.

## 마을·장비·던전

새 모험은 마을 광장에서 시작합니다. 광장 가운데에 있는 **촌장 발렌의 집**에 들어가
촌장과 대화하면 모험이 시작되고 녹슨 철검과 회복약을 받습니다.

| 장소 | 인물 | 하는 일 |
| --- | --- | --- |
| 촌장 발렌의 집 (가운데) | 촌장 발렌 | 메인 임무, 진행도에 따른 조언 |
| 약초상의 오두막 (왼쪽) | 약초상 마르타 | 부탁 「약초상의 부탁」 |
| 노기사 가렌의 거처 (오른쪽) | 은퇴한 기사 가렌 | 부탁 「녹슨 맹세의 검」 |
| 광장 노점 (분수 오른쪽) | 잡화상 로건 | 무기·방어구·회복약 판매, 공략 조언 |
| 붉은 바위 협곡 | 떠돌이 상인 토비 | 부탁 「협곡의 불청객」 |

로건의 노점에서는 철검·은검·가죽 갑옷·사슬 갑옷과 회복 포션을 살 수 있습니다.
무기는 공격력을, 갑옷은 방어력을 높입니다. 필드와 던전 전투에서 금화를 모아 더
좋은 장비를 마련하세요.

마을에는 네 방향으로 출구가 있습니다.

| 출구 | 목적지 | 특징 |
| --- | --- | --- |
| 동쪽 | 바람 부는 숲길 → 바람의 제단 | 숲과 개울, 슬라임·고블린 |
| 서쪽 | 붉은 바위 협곡 → 대지의 폐광 | 바위 협곡, 고블린 사냥꾼 토비 |
| 남쪽 | 메마른 화산 기슭 → 불꽃의 신전 | 용암 지대, 출현율이 가장 높음 |
| 북쪽 | 별빛 제단 | 전투 없는 작은 숲속 제단 |

필드 끝의 입구로 들어가면 2층짜리 제단 던전이 나오고, 2층에 제단의 수호자가
기다립니다. 세 제단을 원하는 순서로 정화해 인장을 모은 뒤 광장의 별빛 분수에
바치세요. 별빛의 검이 깨어나면 흑기사 말포스와 최종 결전을 치릅니다. 말포스를
물리치면 마을 사람들이 광장에 모여 결계의 복원을 축하하고, 주인공이 수호 기사로
임명되는 에필로그(4막)와 엔딩 화면이 이어집니다. 엔딩 뒤에도 마을을 자유롭게 둘러볼
수 있으며, 별빛 분수에서 에필로그를 다시 볼 수 있습니다.

스페이스바로 상자·입구·계단을 사용합니다. 이전 버전의 세이브는 동쪽 숲길에서
이어서 시작합니다.

## 소스에서 실행

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Windows 단일 실행 파일 빌드

```powershell
pyinstaller --onefile --windowed --add-data "assets;assets" --icon "assets/icon.ico" --name "ChroniclesOfPixel" main.py
```

주인공은 16×24 픽셀의 치비형 모험가 스프라이트이며, 맵 타일과 상자·몬스터는 16×16
픽셀 아트로 표현합니다. 장착한 무기와 갑옷은 주인공 외형에도 반영됩니다. 석재 프레임과
양피지 색상으로 중세 RPG 분위기를 냈습니다. 스프라이트 원본 코드는 `utils/pixel_art.py`,
한글 폰트 라이선스는 `assets/fonts/OFL.txt`에 있습니다.
