# 별빛 결계의 수호자 (Chronicles of Pixel)

Pygame CE로 만든 한글 2D 탑뷰 RPG입니다. 거점 마을 오크밸리를 중심으로 동·서·남·북
네 방면의 필드와 제단 던전을 탐험하고, 별빛 결계를 되살리세요.

게임 기획서: [별빛 결계의 수호자 게임 기획서 (PDF)](docs/별빛%20결계의%20수호자%20게임%20기획서.pdf)

## Windows에서 다운로드 및 실행

1. [최신 릴리즈 페이지](https://github.com/csw94/Star/releases/latest)를 엽니다.
2. 릴리즈의 Assets에서 **ChroniclesOfPixel.exe**를 다운로드합니다.
3. 다운로드한 EXE 파일을 더블 클릭해 실행합니다. Python 설치는 필요하지 않습니다.

세이브 데이터는 Windows 사용자 앱 데이터 폴더에 저장됩니다. EXE에 한글 폰트가
포함되어 있어 별도의 에셋 폴더 없이 실행할 수 있습니다.

## 조작 방법

| 키 | 하는 일 |
| --- | --- |
| 방향키 / WASD | 이동, 메뉴 고르기 |
| 스페이스 / Enter / Z | 대화·조사·상자 열기·문과 계단 이용, 대화 넘기기(글자가 나오는 중이면 한 줄을 바로 표시) |
| I / Tab | 상태 화면 (능력치·장비·기술·부탁 진행도). ←→로 **지도**·**도감**·**업적**·**가방** 페이지 |
| B | 가방: 필드에서 물약 쓰기, 무기·방어구·장신구 바꿔 끼기 |
| O | 설정 (배경음악·효과음 음량, 화면 크기) |
| F5 / 저장 버튼 | 지금 상태 저장 |
| M | 소리 켜기 / 끄기 |
| ESC | 저장하고 타이틀로 (메뉴에서는 뒤로) |
| Enter / 스페이스 | 전투 행동 결정, 연출 빨리 보기 |

전투와 메뉴는 마우스로도 고를 수 있습니다. 타이틀 화면의 **조작법**에서도 같은 안내를 볼 수 있습니다.

## 설정

타이틀의 **설정** 또는 필드에서 **O** 키로 엽니다.

- 배경음악과 효과음 음량을 0~10 단계로 따로 조절합니다.
- 화면 크기는 기본(800×600), 1.5배, 2배, 전체 화면 중에서 고릅니다. 모니터에 들어가지 않는 크기는 목록에 나오지 않습니다. 전체 화면에서는 4:3 화면을 가운데에 맞춥니다.
- 대화 글자 속도를 느림·보통·빠름·즉시 중에서 고릅니다.
- 모험 중에 열면 **난이도**도 바꿀 수 있습니다.
- 설정은 세이브와 같은 폴더의 `settings.json`에 저장되어 다음 실행 때도 유지됩니다.

## 난이도와 저장

새 모험을 시작할 때 난이도를 고릅니다. **쉬움**은 적 HP 80%·받는 피해 75%, **보통**은 기본 균형,
**어려움**은 적 HP 125%·받는 피해 125%에 골드 120%입니다. 난이도는 세이브마다 따로 저장됩니다.

필드·마을·던전을 돌아다니는 동안 1분마다 자동으로 저장되며(화면 오른쪽 위에 "자동 저장됨" 표시),
창을 닫을 때도 진행 중인 모험을 저장한 뒤 종료합니다.

## 세이브 슬롯

타이틀 화면에서 **모험 이어하기**를 선택하면 3개의 슬롯 중 저장 기록을 고를 수
있습니다. 슬롯마다 레벨, 플레이 시간, 모은 인장 수, 엔딩 여부가 표시됩니다. 새 모험은
**새 모험 시작**을 선택한 뒤 슬롯을 지정하세요. 이미 기록이 있는 슬롯은 덮어쓰기 전에
확인을 받습니다. 필요 없는 기록은 슬롯 카드의 휴지통 버튼이나 **Del** 키로 지울 수 있고,
지우기 전에 한 번 더 확인합니다. 엔딩 화면에는 플레이 시간과 전투 승리 수 같은 모험 기록이 나옵니다.

## 마을·장비·던전

오크밸리는 광장을 중심으로 **동쪽 구역**(여관·대장간)과 **남쪽 구역**(도서관·물약 상점·공원)으로 넓어졌습니다.
네 건물은 모두 문 앞에서 SPACE를 누르면 안으로 들어가고, 주인은 실내 계산대에서 기다립니다.
집마다 벽 재질과 지붕 모양이 달라서(초가 오두막, 2층 여관, 돌로 지은 대장간, 벽돌 도서관 등) 멀리서도 구분됩니다.
새 모험을 시작하면 꼬마 토미가 달려와 촌장 집까지 길을 안내합니다.

| 시설 | 주인 | 하는 일 |
| --- | --- | --- |
| 여관 「졸린 곰」 | 로사 | 금화(10 + 레벨×2)를 내고 HP·MP 완전 회복, 공략 힌트가 담긴 소문 |
| 브론의 대장간 | 브론 | 장착한 무기(공격 +3/단계)와 방어구(방어 +2/단계)를 +3까지 강화 |
| 별빛 도서관 | 에델 | 세계관과 공략 힌트가 담긴 책 6권 |
| 미라의 물약 상점 | 미라 | 회복약, 마나 물약, 해독제, 엘릭서(제단 3곳 정화 후) |

전투의 **아이템** 버튼으로 가진 소모품 중 하나를 골라 쓸 수 있고, **가방**(B)에서는 필드에서도 물약을 마시거나
장비를 바꿔 낄 수 있습니다.

새 모험은 마을 광장에서 시작합니다. 광장 가운데에 있는 **촌장 발렌의 집**에 들어가
촌장과 대화하면 모험이 시작되고 녹슨 철검과 회복약을 받습니다.

| 장소 | 인물 | 하는 일 |
| --- | --- | --- |
| 촌장 발렌의 집 (가운데) | 촌장 발렌 | 메인 임무, 진행도에 따른 조언 |
| 약초상의 오두막 (왼쪽) | 약초상 마르타 | 부탁 「달빛 약초」 |
| 노기사 가렌의 거처 (오른쪽) | 은퇴한 기사 가렌 | 부탁 「노기사의 검」, 이어서 「동굴 소탕」(동굴 박쥐) |
| 광장 노점 (분수 오른쪽) | 잡화상 로건 | 장비·회복약 판매. 제단을 하나 정화하면 부탁 「용암석 수집」(마그마 슬라임) |
| 광장 | 마을 주민 | 부탁 「숲의 사냥꾼」(숲늑대) |
| 붉은 바위 협곡 | 떠돌이 상인 토비 | 부탁 「고블린 소탕」 |
| 여관·대장간·도서관·공원 | 로사·브론·에델·토미 | 부탁 「서리 늑대 스튜」「전갈 껍질 망치」「마물 기록」「토미의 모험」 |
| 서리 고원 | 사냥꾼 하른 | 부탁 「고원의 정령」(서리 정령) → 얼음 심장(빙결 면역) |

새 부탁 세 개는 상점에서 팔지 않는 전용 장신구(늑대 송곳니 부적, 용암석 팔찌, 수호자의 훈장)를 보상으로 줍니다.

로건의 노점은 무기·방어구·장신구·소모품 네 칸으로 나뉘고, 제단을 정화할 때마다 새 물건이
들어옵니다. 산 장비는 바로 장착되며, 이미 가진 장비는 노점에서 언제든 다시 바꿔 낄 수 있습니다.

| 종류 | 물건 | 특징 |
| --- | --- | --- |
| 무기 | 강철 장검, 바람의 단검, 대지의 전투망치, 화염검, 폭풍 할버드 | 속성 무기는 일반 공격에도 속성이 실림. 단검·할버드는 치명타, 망치는 기절, 화염검은 화상 |
| 방어구 | 기사단의 흉갑, 마도사의 로브, 용비늘 갑옷, 오로라 갑옷 | 흉갑은 최대 HP, 로브는 최대 MP, 용비늘은 HP와 화상 면역, 오로라는 HP·MP 모두 |
| 장신구 | 해독의 부적, 바람의 깃털, 마나의 반지, 힘의 팔찌, 따뜻한 목도리 | 독 면역, 회피, 승리 시 MP 추가 회복, 공격력, 빙결 면역 |
| 소모품 | 회복약(소), 고급 회복약 | HP 50 / 120 회복, 종류별 10개까지 |

별빛의 검은 빛 속성이라 흑기사 말포스의 약점을 찌릅니다. 필드와 던전 전투에서 금화를
모아 장비를 마련하세요. 마르타의 오두막과 가렌의 거처에 있는 **침대**에서
쉬면 HP와 MP가 모두 무료로 회복되고 저장됩니다.

마을에는 네 방향으로 출구가 있습니다.

| 출구 | 목적지 | 나오는 적 |
| --- | --- | --- |
| 동쪽 | 바람 부는 숲길 → 바람의 제단 | 슬라임, 숲늑대, 독버섯 요정, 고블린 |
| 서쪽 | 붉은 바위 협곡 → 대지의 폐광 | 붉은 전갈, 협곡 도적, 고블린 (상인 토비) |
| 남쪽 | 메마른 화산 기슭 → 불꽃의 신전 | 불도마뱀, 마그마 슬라임, 고블린 |
| 북쪽 | 별빛 제단 → 서리 고원 → 얼음 제단 | 제단 공터는 전투 없음. 서리 고원에는 서리 늑대, 얼음 슬라임, 서리 정령 |

**서리 고원**으로 가는 북쪽 아치는 얼음 결계로 막혀 있다가, 제단 두 곳을 정화하면 녹아 열립니다.
눈밭과 얼어붙은 호수를 지나 고원 꼭대기의 얼음 제단으로 올라가세요. 얼음 계열 적은 공격할 때
주인공을 **얼려** 한 턴 움직이지 못하게 할 수 있습니다(연속으로 얼지는 않습니다).

남쪽 화산 기슭은 마을 문에서 시작해 아래로 내려가면 신전이 나옵니다. 제단 던전에는
박쥐·해골 병사 등 던전마다 다른 적이 나옵니다.

필드 끝의 입구로 들어가면 2층짜리 제단 던전이 나오고, 2층에 제단의 수호자가
기다립니다. 네 제단을 정화해 인장을 모은 뒤 광장의 별빛 분수에
바치세요. 별빛의 검이 깨어나면 흑기사 말포스와 최종 결전을 치릅니다. 말포스를
물리치면 마을 사람들이 광장에 모여 결계의 복원을 축하하고, 주인공이 수호 기사로
임명되는 에필로그(4막)와 엔딩 화면이 이어집니다. 엔딩 뒤에도 마을을 자유롭게 둘러볼
수 있으며, 별빛 분수에서 에필로그를 다시 볼 수 있습니다.

## 엔딩 후: 별빛 심연

흑기사 말포스를 물리친 뒤 북쪽 별빛 제단을 조사하면 제단 아래 **별빛 심연**(3층)이 열립니다.
1~2층에는 그림자 늑대·공허 슬라임·심연 기사가 나오고, 2층 상자에는 **별의 목걸이**가 있습니다.
3층의 **심연의 군주 녹스**는 3턴마다 심연의 폭풍을 일으키며, 쓰러뜨리면 최강 장신구
**심연의 왕관**을 얻습니다. 레벨 12 이상과 좋은 장비를 갖추고 도전하세요.

## 도감

상태 화면의 **도감** 페이지에는 적 22종이 칸으로 나옵니다. 만난 적은 그림·약점·처치 수가 보이고,
아직 못 만난 적은 실루엣으로 남아 있습니다. 위쪽에는 만난 적과 모은 장비의 수가 표시됩니다.

## 업적과 회차 플레이

첫 승리, 네 개의 인장, 도감 완성, 어려움으로 엔딩, 1시간 안에 엔딩 등 업적 14개가 있습니다. 달성하면
화면 위에 알림이 뜨고, 상태 화면의 **업적** 페이지에서 모두 볼 수 있습니다.

엔딩을 본 뒤 촌장과 이야기하면 **새 여정(회차 플레이)**을 시작할 수 있습니다. 레벨·장비·골드·도감·업적은
그대로 이어지고, 제단과 부탁은 처음부터 다시 진행합니다. 회차가 오를 때마다 적 HP +160%, 받는 피해 +60%,
골드·경험치 +30%가 됩니다.

## 지도와 목표

상태 화면(I / Tab)에서 ←→를 누르면 지금 있는 곳의 지도가 나옵니다. 열지 않은 상자, 약초,
출입구, 계단, 보스, 주민, 상점, 침대가 표시되고, 아래에 **다음 목표**가 한 줄로 안내됩니다.

## 성장과 전투

- 적을 쓰러뜨리면 경험치를 얻고, 레벨이 오르면 능력치가 오르고 HP·MP가 모두 회복됩니다.
- 기술 8가지를 레벨에 따라 배웁니다: 빛의 탄, 회복의 빛, 수호 자세, 바람 베기, 대지 강타, 화염 참격, 그리고 Lv.10 별빛 폭풍(가장 강한 빛 공격)과 Lv.12 성스러운 기도(큰 회복·상태이상 해제).
- 적마다 약점·저항 속성이 있습니다. 약점은 1.5배, 저항은 절반 피해를 줍니다. 독·화상·기절·빙결 상태이상도 있습니다.
- 이기면 MP가 2 회복됩니다. 지면 **다시 도전**(전투 직전 상태로)과 **마을로 돌아가기**(HP 절반) 중에서 고릅니다.
- 제단을 정화하면 바람(회피 15%), 대지(최대 HP·방어력), 불(공격력), 얼음(최대 MP·방어력)의 가호를 받습니다.
- 흑기사 말포스는 HP가 절반 아래로 떨어지면 각성해 더 강해집니다.

효과음과 배경음악은 모두 코드로 합성한 8비트 사운드라서 별도의 음원 파일이 없습니다.
예전 버전의 세이브는 불러올 때 현재 맵에 맞게 위치가 자동으로 보정됩니다.

## 소스에서 실행

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Windows 단일 실행 파일 빌드

```powershell
pyinstaller --onefile --windowed --add-data "assets;assets" --icon "assets/icon.ico" --name "ChroniclesOfPixel" main.py
```

그래픽은 외부 이미지 없이 코드로 그린 픽셀 아트입니다. 주인공과 마을 사람은 16×24
치비 비율이며, 주인공은 방향마다 4프레임 걷기 동작이 있고 장착한 무기와 갑옷이 외형에
반영됩니다. UI는 나무 프레임과 양피지로 꾸몄습니다. 스프라이트 코드는 `utils/pixel_art.py`,
사운드 합성 코드는 `utils/audio.py`, 한글 폰트 라이선스는 `assets/fonts/OFL.txt`에 있습니다.

GitHub Actions가 `main`에 올라온 커밋마다 테스트를 돌리고, 버전 태그를 올리면 테스트 → EXE 빌드 → 릴리즈(노트는 HANDOVER의 릴리즈 기록에서 가져옴) 순서로 진행합니다.

전투 밸런스는 `tools/balance_sim.py`로 시뮬레이션해 조정합니다.

```powershell
.venv\Scripts\python.exe tools\balance_sim.py 4 300
```
