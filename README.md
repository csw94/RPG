# Chronicles of Pixel

Pygame CE로 만든 한글 2D 탑뷰 RPG입니다. 마을과 필드를 탐험하고, 대장간에서 장비를
마련한 뒤 별도의 던전에 도전하세요.

## Windows에서 다운로드 및 실행

1. [최신 릴리즈 페이지](https://github.com/csw94/RPG/releases/latest)를 엽니다.
2. 릴리즈의 Assets에서 **ChroniclesOfPixel.exe**를 다운로드합니다.
3. 다운로드한 EXE 파일을 더블 클릭해 실행합니다. Python 설치는 필요하지 않습니다.

세이브 데이터는 Windows 사용자 앱 데이터 폴더에 저장됩니다. EXE에 한글 폰트가
포함되어 있어 별도의 에셋 폴더 없이 실행할 수 있습니다.

## 조작 방법

- 이동: 방향키 또는 WASD
- 상호작용·상자 열기·문/계단 이용: 스페이스바
- 저장: F5 또는 필드 화면의 저장 버튼
- 타이틀로 돌아가기: ESC (현재 진행 상황을 저장합니다)
- 전투: 방향키 또는 WASD로 선택한 뒤 Enter/스페이스바, 또는 마우스로 행동 선택
- 상점: 방향키로 물품 선택 후 Enter, ESC로 마을에 돌아가기

## 세이브 슬롯

타이틀 화면에서 **모험 이어하기**를 선택하면 3개의 슬롯 중 저장 기록을 고를 수
있습니다. 새 모험은 **새 모험 시작**을 선택한 뒤 슬롯을 지정하세요. 이미 기록이
있는 슬롯은 덮어쓰기 전에 확인을 받습니다. 기존 저장 기록은 1번 슬롯에 보존됩니다.

## 마을·장비·던전

새 모험은 마을에서 시작합니다. 대장간 주인에게 말을 걸면 철검·은검·가죽 갑옷·
사슬 갑옷과 회복 포션을 살 수 있습니다. 무기는 공격력을, 갑옷은 방어력을 높입니다.
필드와 던전 전투에서 금화를 모아 더 좋은 장비를 마련하세요.

마을 남쪽 문을 나서면 필드가 나오고, 필드 동쪽의 계단을 통해 별도의 던전에 들어갈
수 있습니다. 던전에는 강화된 해골 병사와 보물상자가 있습니다. 스페이스바로 상자와
계단을 사용하세요.

## 소스에서 실행

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Windows 단일 실행 파일 빌드

```powershell
pyinstaller --onefile --windowed --add-data "assets;assets" --name "ChroniclesOfPixel" main.py
```

캐릭터, 맵 타일, 상자, 몬스터는 16×16 픽셀 아트 스프라이트로 표현합니다. 석재 프레임과
양피지 색상으로 중세 RPG 분위기를 냈습니다. 스프라이트 원본 코드는 `utils/pixel_art.py`,
한글 폰트 라이선스는 `assets/fonts/OFL.txt`에 있습니다.
